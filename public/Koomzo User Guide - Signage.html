Signage

Every screen your business runs — menu boards, price screens, the lobby rate card, the now-serving wall — from one place. Prices are read from the till, never retyped. Shared chapters are in the Platform chapters.

Signage · Part 1

Is this for me?

If you have a TV on the wall, Signage puts it to work. Any TV with an Android stick, or a smart TV, becomes a Koomzo screen.

Restaurants and bars

The menu with today's prices; breakfast, lunch and the bar menu by time of day.

Shops and supermarkets

Promotions and multibuys in the aisle, updated when the price changes.

Hotels and offices

Lobby rate card, event of the day, directions — and the now-serving screen for a queue.

What you get at each level

LiteA screen that plays

  • Screens: which are alive, what they play
  • Playlists that loop round the clock

Signage · Part 2

Set up Lite

About 20 minutes for the first screen.

  1. Get a playerAn Android TV stick or a smart TV, on the same Wi-Fi as the till. Player app — available soon
  2. Pair the screenThe TV shows a 6-digit code. Screens → Pair a screen → type the code, give it a name and a place.
  3. Make a boardBoards → pick the category it shows (Breakfast, Drinks, Room rates). Prices come from the till.
  4. Build a playlistPlaylists → add the board, a photo, a promotion; set how long each shows.
  5. PublishThe screen downloads the playlist and plays it from its own memory.

Screens

The left rail: Screens, Playlists, Media, Boards, Schedule, Proof of play, and Setup at the bottom. The prototype's screen labels are partly in French.

Screens Lite

1234567
  1. Badge — screens that need a look.
  2. Sites — one branch or all of them.
  3. Pair a screen — type the code the TV shows.
  4. Playing · offline · out of date · waiting to pair.
  5. Offline — no heartbeat; the screen keeps playing what it has.
  6. Out of date — still playing an older version, usually because its memory is nearly full.
  7. Waiting to pair — the code expires in 10 minutes.

Playlists Lite

123456
  1. Playlists — one per place: restaurant, grocery aisle, salon queue, reception.
  2. Size — checked against the screen with the least free memory.
  3. Items — drag to reorder; each shows for a set number of seconds.
  4. Until 11:00 — an item can play only part of the day. Mid
  5. Add a board, photo, video or notice.
  6. Publish — screens pick it up at their next heartbeat.

Boards Lite

12345

  2. No prices stored here — the board is linked to a category and reads prices when it plays.

  4. Preview — exactly what the TV will show.
  5. Save.

Signage · Part 5

When something goes wrong

The TV shows the wrong menu.

Check which playlist the screen has, and the schedule. A breakfast item marked Until 11:00 plays only in the morning.

A price changed but the board didn't.

The screen updates at its next heartbeat. If it shows Offline, it is playing its last copy — fix the Wi-Fi and it catches up.

The TV lost Wi-Fi.

It keeps playing what it has. Nothing goes black. Screens shows it offline until it comes back.

A promotion is still showing after it ended.

Give promotions and notices an end date; they leave by themselves. Remove it from the playlist and publish.

The pairing code expired.

The TV shows a new code. Type that one.
