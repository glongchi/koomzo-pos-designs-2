Guide de module

File d'attente

Tickets, guichets et écran d'appel — pour tout lieu où l'on attend : agence bancaire, clinique, mairie, salon, passe d'une cuisine. Les chapitres communs sont dans les chapitres Plateforme.

Les captures montrent la version anglaise du prototype. Les boutons sont donnés en français, avec le libellé anglais entre parenthèses quand c'est utile.

File d'attente · Partie 1

Est-ce pour moi ?

La configuration propose une forme de départ pour chaque type de lieu. Le principe reste le même : prendre un ticket, attendre à l'écran, être appelé à un guichet.

Agence bancaire · microfinance

Retrait, dépôt, services au compte, conseiller — plusieurs guichets.

Administration · clinique

Nouvelle demande, renouvellement, aide technique, paiements.

Salon · barbier

Les clients de passage attendent par prestation ; chaque fauteuil appelle le suivant.

Passe de cuisine

Tickets sur place, à emporter, livraison appelés au retrait.

File d'attente · Partie 4

Les écrans

La File d'attente a cinq modes : Affichage (Display), Guichet (Serve), Accueil (Intake), Supervision (Supervise) et Configuration. Chaque appareil lance celui dont il a besoin — la télé l'Affichage, chaque guichet le mode Guichet.

Affichage Mid

123456
  1. Chaque guichet ou fauteuil — le ticket servi et le service.
  2. En pause — De retour bientôt ; personne n'y est envoyé.
  3. Avancez s'il vous plaît — le ticket qui vient d'être appelé, mis en avant.
  4. Ensuite — avec une attente estimée pour chacun.
  5. En attente · ouverts — combien attendent, combien de guichets sont ouverts.
  6. Appareils synchronisés — l'écran, les guichets et l'accueil sur le même réseau.

Accueil, Guichet, Supervision

Accueil Lite

De grands boutons, un par service. Le client touche et reçoit un numéro — imprimé, à l'écran, ou par SMS.

Guichet Lite

Un guichet : Appeler le suivant, Rappeler, Absent, Terminé, Pause. Affiche qui attend pour ses services.

Supervision Full

Tous les guichets d'un coup d'œil ; ouvrir, fermer, déplacer un ticket, temps d'attente par rapport à l'objectif.

File d'attente · Partie 5

En cas de problème

Un guichet ferme avec du monde en attente.

Leurs tickets restent dans la file ; les autres guichets qui traitent ce service les appellent ensuite. Personne ne reprend de ticket.

Un client a manqué son numéro.

Rappelez-le, ou marquez Absent. Un absent qui revient peut être remis en tête par le superviseur.

La télé d'appel est éteinte.

Les guichets continuent d'appeler ; annoncez le numéro à voix haute en attendant. La télé se rattrape à la reconnexion.

Un client prioritaire arrive.

Remettez un ticket prioritaire à l'accueil. Il passe avant les tickets normaux du même service.

Le courant a sauté.

Les appareils sur batterie continuent sur le réseau local. La file est la même au retour du courant.
